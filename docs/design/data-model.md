# データモデル設計書(v1.0 確定、2026-11-22)
状態: **確定**(D-007)。変更する場合は `docs/decisions.md` に理由を記録する。
根拠: `docs/research/layers-classes-bim.md`、`docs/operations.md`。

## 0. 基本方針
- 用語・構造は Vectorworks に合わせる。
- 全範囲(シートレイヤ、ビューポート、リソース、ストーリ、データ)の「入る場所」を v1 で決める。実装は段階的に。未実装の項目も、ファイルに書かれていれば**読み込んで、そのまま保存し直す**(消さない)。
- 参照は名前ではなく**ID**で行う。クラス名を変えても、図形との結び付きが切れないようにするため。
- 寸法の内部単位は **mm**(実寸)。縮尺は「見せ方」で、図形の座標は縮尺に関係なく実寸で持つ。
- 線の太さ・文字の大きさは**紙の上の大きさ**(mm、pt)で持つ。縮尺を変えても、印刷上の太さは変わらない(Vectorworks と同じ)。
- 座標は X 右・Y 上(Vectorworks と同じ)。

## 1. 全体構造
```
ファイル(.vws)
├─ formatVersion           … 形式の版。移行処理の起点
├─ 書類設定                 … 単位、原点、ファイル情報
├─ クラス一覧               … 「なし」「寸法」は必須・削除不可
├─ デザインレイヤ一覧        … 重ね順つき。各レイヤが図形を持つ
├─ シートレイヤ一覧          … ビューポートと注記を持つ
├─ ストーリ一覧(予約)       … 階と基準高さ(レベル)
├─ リソース                 … 線種、ハッチング、模様、文字スタイル、
│                              シンボル(予約)、マテリアル(予約)、レコード書式(予約)
└─ 作業状態                 … アクティブなレイヤ・クラス、表示状態
```

## 2. クラス
| 項目 | 内容 |
| --- | --- |
| id | 不変のID |
| name | 表示名。「-」で階層を表す(例: `01_壁-既存`) |
| order | 並び順 |
| visibility | 表示 / グレー表示 / 非表示 |
| attributes | クラスの属性(下の「属性」と同じ項目) |
| useAtCreation | 「作成時にクラスの属性を使う」。新しく描いた図形の属性を「クラスに従う」にするか |
| builtin | `none`(なし)/ `dimension`(寸法)。この2つは削除不可、名前変更は可 |

## 3. デザインレイヤ
| 項目 | 内容 |
| --- | --- |
| id, name | |
| order | 重ね順 |
| scale | 縮尺の分母(1:50 なら 50)。レイヤごとに変えられる |
| visibility | 表示 / グレー表示 / 非表示 |
| locked | |
| elevation | 高さ(mm)。3D・ストーリ用の予約 |
| storyId | 所属するストーリ(予約、省略可) |
| objects | 図形の並び(並び順=前後関係) |

## 4. 図形(共通項目)
| 項目 | 内容 |
| --- | --- |
| id | 不変のID |
| type | 種類(下表) |
| classId | 所属クラス。既定は「なし」 |
| attributes | 属性。項目ごとに「クラスに従う」か「直接指定」 |
| locked | ロック |
| records | 付加データ(材料・品番・コストなど)。予約 |

### 図形の種類
| type | Phase | 形の持ち方 |
| --- | --- | --- |
| line | 2 | 始点、終点 |
| rect | 2 | 中心、幅、高さ、回転角 |
| ellipse | 2 | 中心、横半径、縦半径、回転角(円は横=縦) |
| arc | 5 | 中心、半径、開始角、終了角 |
| polyline | 2 | 頂点の列(各頂点: 角/円弧/曲線の種別)、閉じているか |
| polygon | 5 | 頂点の列、閉じているか |
| text | 5 | 位置、文字列、文字スタイル参照、回転 |
| dimension | 5 | 計測点、寸法線の位置、寸法の書式 |
| group | 5 | 子図形の並び |
| image | 5 | 画像データ参照、配置 |
| symbol | 予約 | シンボル定義の参照、配置 |
| unknown | — | 未対応の図形。中身を保持して書き戻す |

## 5. 属性
各項目は `{ "byClass": true }` か `{ "value": ... }` のどちらか。
| 項目 | 内容 |
| --- | --- |
| penColor | 線の色(RGB) |
| penOpacity | 線の不透明度(0〜100) |
| lineWeight | 線の太さ(紙の上の mm) |
| lineType | 実線、または線種リソース参照 |
| fill | なし / 単色 / 模様参照 / ハッチング参照 / タイル参照(グラデーション・イメージは予約) |
| fillColor | 面の色 |
| fillOpacity | 面の不透明度(0〜100) |

属性の決まり方: 図形の項目が「直接指定」ならその値。「クラスに従う」ならクラスの値。ビューポートの「クラス上書き」があれば、出図時にさらに上書きされる。

## 6. シートレイヤとビューポート
- シートレイヤ: id、番号、名前、用紙サイズ、ビューポートの並び、注記(文字・線など)。
- ビューポート: 表示するデザインレイヤ、各クラスの表示状態、縮尺、表示中心、切り抜き範囲。
  - **クラス上書き**: クラスごとに属性を上書き(既存・撤去・新設の描き分け)。
  - **レイヤ上書き**: レイヤごとに色・不透明度などを上書き。

## 7. リソース
| 種類 | Phase | 内容 |
| --- | --- | --- |
| 線種 | 3 | 破線のパターン(紙の上の長さ) |
| ハッチング | 4 | 線の組の定義(角度、間隔、線の属性) |
| 模様 | 4 | 塗りの模様(白黒の柄)。作成者がよく使う |
| タイル | 4 | 塗りのタイル |
| 文字スタイル | 5 | フォント、大きさ(pt)、太字など |
| シンボル | 予約 | 再利用する図形のまとまり |
| マテリアル | 予約 | 仕上げ材(ハッチング・テクスチャ・データをまとめたもの) |
| レコード書式 | 予約 | 図形に付けるデータの項目定義 |

## 8. ストーリとレベル(予約、3D以降)
- ストーリ: 名前、高さ。
- レベル: ストーリ内の基準高さ(床仕上げ、天井など)。図形の高さをレベルに紐付ける。

## 9. 変更の記録(コマンドとUndo/Redo)
- 書類へのすべての変更は「コマンド」で行う。画面操作も CLI も同じコマンドを使う。
- 各コマンドは JSON で表せる(例: `{"cmd":"addLine","layer":"…","from":[0,0],"to":[1000,0]}`)。これがそのまま CLI の入力になり、テストの手順書にもなる。
- 各コマンドは「元に戻す」ための情報を持つ。Undo/Redo は記録の巻き戻しと再実行。
- 複数の変更を1回の Undo で戻せるよう、まとめる仕組みを持つ(例: ⌘D 複製の後に移動)。

## 10. ファイル形式
```json
{
  "formatVersion": 1,
  "app": "VectorStation",
  "document": {
    "settings": { "units": "mm" },
    "classes": [
      { "id": "c-none", "name": "なし", "builtin": "none", "visibility": "visible", "attributes": {} },
      { "id": "c-dim", "name": "寸法", "builtin": "dimension", "visibility": "visible", "attributes": {} },
      { "id": "c-grid", "name": "00_基準線", "visibility": "visible",
        "attributes": { "lineType": { "value": "lt-dashdot" }, "lineWeight": { "value": 0.18 } } }
    ],
    "designLayers": [
      { "id": "l-1f", "name": "1F平面", "order": 0, "scale": 50, "visibility": "visible",
        "objects": [
          { "id": "o-1", "type": "line", "classId": "c-grid",
            "geometry": { "from": [0, 0], "to": [6000, 0] },
            "attributes": { "lineType": { "byClass": true } } }
        ] }
    ],
    "sheetLayers": [],
    "resources": { "lineTypes": [], "hatches": [] }
  }
}
```
- 拡張子は仮に `.vws`(既存形式との重複は確認中)。
- 版を上げるときは、前の版から変換する処理を必ず書く。各版の見本ファイルを `tests/fixtures/` に残し、すべての版が開けることをテストで守り続ける。

## 11. 作成者の回答(2026-11-22)
1. 単位は mm。
2. 模様・ハッチング・タイル・透明度、すべてよく使う。
3. レイヤ・クラスのグレー表示・非表示は頻繁に使う。
4. 1ファイルが理想。大規模案件や低スペックPCではファイルを分ける。
5. 現時点で合わない点はない。オーガナイザでクラス・デザインレイヤ・シートレイヤの並び順をドラッグ&ドロップで変えている。
