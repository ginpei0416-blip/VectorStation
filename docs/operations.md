# 再現したい操作リスト
作成者が Vectorworks で実際に使っている操作。実装の順番と「できた」の判断の根拠。人間向けの同じ内容は Notion にある。
2D 機能はほぼすべて必要(2026-11-22 確認)。順番は docs/roadmap.md の依存関係で決める。

## 土台
- レイヤ / クラス / 縮尺 / オブジェクト情報パレット
- ⌘D: 複製 / ⌘M: 数値指定での移動

## 属性
- 線の太さ / 線種 / 線の色 / 面の色 / ハッチング / 模様(パターン) / 透明度(線と面で別々)

## 出図
- シートレイヤ / ビューポート

## 再利用
- リソース(リソースブラウザ)

## 作図ツール
- 直線 / 長方形 / 円・楕円 / 円弧 / ポリライン / 曲線(スプライン) / 多角形 / 文字

## 編集
- 選択(クリック・範囲) / 移動・回転・拡大縮小 / ミラー / オフセット / トリム・延長 / フィレット・面取り / 整列・配置 / グループ化 / ロック / 結合・分割

## 補助
- スナップ(スマートカーソル) / グリッド / 寸法線 / 計測 / ナビゲーションパレット / レイヤ・クラスの表示・ロック / 画像の貼り付け

## 入出力
- DXF / DWG / PDF出力 / 印刷 / .vwx は書き出しスクリプト経由(D-001, D-002)

## 不明点
- 細かな挙動(各ツールのモード、ショートカット全般)は未記録。必要になった時点で、作成者の Vectorworks 2023 Architect で実機確認する。

## 実機で観察したこと(Vectorworks 2023 Architect 日本語版、作成者の Windows PC)
- 2026-11-22: 既定のクラス名は「一般」(英語版の None)。「寸法」はそのまま。
- 2026-11-22: スクリプトの実行は「ツール」→「プラグイン」→「スクリプトを実行...」(「スクリプト」というメニューはない)。
- 2026-11-22: 実務の展開図(東急スクエアA ギブソンエリア)を書き出した結果: 直線 86,467、ポリライン 3,609、長方形 2,250。未対応: 円弧 4,729、グループ 1,821、回転した長方形・楕円 709、文字 123、寸法 56、シンボル 45、プラグインオブジェクト 31、角丸長方形 1。書き出しに約30秒。グラデーションの面が 806 か所(透過の黒・黄など)。
  → 次に対応すべき順: 円弧、グループ、回転した長方形・楕円(数が多い)。文字・寸法は出図に必須。
