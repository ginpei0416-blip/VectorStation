### 2026-11-22 Phase 1 第1弾: 書類・クラス・レイヤ・図形・保存・Undo
- 何を変えたか:
  - 書類の土台(vs-core)を作った。クラス(「なし」「寸法」は必須・削除不可)、デザインレイヤ(レイヤごとの縮尺、表示/グレー表示/非表示、ロック)、図形(直線・長方形・円/楕円・ポリライン)。
  - 属性は項目ごとに「クラスに従う」か「直接指定」。「作成時にクラスの属性を使う」クラスで描くと、自動でクラスの見た目になる。
  - 操作: クラス・レイヤの追加/変更/削除/並べ替え、図形の追加/削除/数値移動(⌘M)/複製(⌘D)/属性・クラス・ロックの変更。すべて取り消し・やり直しができる。途中で失敗した操作は書類を何も変えない。
  - 保存・読込(vs-io)。形式1。知らない項目や未対応の図形は消さずに書き戻す。新しすぎる版は、わかる言葉で断る。
  - コマンドライン(vs-cli)。手順を JSON で書いて実行できる。見本: examples/basic-plan.json(通り芯・壁・家具・柱の簡単な平面)。
  - GitHub で Windows・Mac・Linux の自動テストが回るようにした。
- どう確認したか:
  - 自動テスト 26件がすべて通過(名前は日本語で、確かめた内容そのもの。例:「クラスの属性を変えるとクラスに従う図形の見た目が一括で変わる」「すべての操作を取り消すと最初の状態に戻る」)。
  - 見本の手順を実行した結果を crates/vs-io/tests/fixtures/v1-basic.vws として保存。この「形式1の見本」が開けることを、今後ずっとテストで守る。
  - 人が確かめる手順: `cargo run -p vs-cli -- run --new examples/basic-plan.json plan.vws` → `cargo run -p vs-cli -- info plan.vws` で、クラスとレイヤと図形の一覧が日本語で出る。
- 未解決・次にやること:
  - 「作成時にクラスの属性を使わない」図形の既定値は、今は固定(黒の実線0.13mm、白の面)。Vectorworks では属性パレットの現在の設定が使われる。画面を作るときに合わせる。
  - ブラウザ版向けの設定(IDの乱数)は未対応。
  - 次: Vectorworks 書き出しスクリプトの第1版(Phase 1 の残り)。
