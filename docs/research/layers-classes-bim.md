# 調査: レイヤ・クラスの使い分けと内装BIM(2026-11-22)
人間向けの同じ内容は Notion「調査: レイヤ・クラスの使い分けと内装BIM」。

## 作成者の使い方
- レイヤ=階・図面の種類、クラス=要素の種類。
- 線の太さ・色・線種は図形ごとに直接設定。通り芯(一点鎖線)・補助線(色付き)などはクラスで属性を決める。
- 縮尺をレイヤごとに変えることがある。

## 参考にした考え方
- Vectorworks 公式: デザインレイヤはゾーン・種類・階で整理。クラスは要素の種類で分け、ビューポートのクラス上書きで既存・撤去・新設などを描き分ける。
- 内装BIM(nanook design / フローワークス): 内装はカタチ・マテリアル・コストに絞る。BIMの価値はテンプレートと運用にあり、個人での整備は困難。→ VectorStation は 2D 優先が正しい。BIM の「入る場所」だけ先に用意する。

## データモデルへの要求
1. 属性ごとに「直接指定」か「クラスに従う」かを持てる。
2. デザインレイヤごとの縮尺。
3. デザインレイヤの高さ(将来のストーリ・3D)。
4. 階層つきのクラス名(例: 壁-既存)。
5. ビューポートのクラス上書き・レイヤ上書き。
6. 図形に付けるデータ(材料・品番・コスト。Vectorworks のレコード相当)。実装は後。
