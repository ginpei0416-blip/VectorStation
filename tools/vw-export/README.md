# Vectorworks 書き出しスクリプト(vs_export.py)
Vectorworks で開いている図面を、VectorStation 形式(.vws)で書き出す。図面は変更しない(読むだけ)。

## 使い方(Vectorworks 2023 日本語版で確認済み)
1. `vs_export.py` を PC に保存する。
2. 書き出したい図面を Vectorworks で開き、保存しておく(書き出し先を決めるため)。
3. メニュー「ツール」→「プラグイン」→「スクリプトを実行...」で `vs_export.py` を選ぶ。図形が多い図面は30秒ほどかかる(その間 Vectorworks は止まって見える)。
4. 終わると、図面と同じフォルダに「図面名.vws」ができ、結果(書き出した図形の数、未対応の図形、注意)が表示される。

## 第1版で書き出すもの
- クラス: 表示状態、線の太さ・色・線種、面(単色・模様・ハッチング・タイル)、不透明度、作成時にクラスの属性を使う
- デザインレイヤ: 縮尺、表示状態、高さ
- 図形: 直線、長方形、円・楕円、多角形、ポリライン(頂点の種類つき)。属性は「クラスに従う/直接指定」を区別
- シートレイヤ: 名前だけ

## まだ書き出せないもの
円弧、文字、寸法、グループ、シンボル、プラグインオブジェクト、回転した長方形・楕円、ほか。
これらは「未対応の図形」として、範囲など中身の一部だけを保持し、終了時に種類ごとの数を報告する。
グラデーション・イメージの面は、単色として書き出す。

## 決まりごと
- Vectorworks が公開しているスクリプト機能(vs モジュール)だけを使う。.vwx の中身は解析しない(D-001, D-006)。
- 線の太さは mil(1/1000インチ)で記録されているので mm に換算する(例: 7mil = 0.1778mm。Vectorworks の画面では 0.18 と表示される)。
